# Round-3 working context

This directory is the handoff packet for the active Delphi research campaign.
It is deliberately inside `new/round3/`, which is gitignored and must never be
committed to the Delphi product repository.

- [`STATE.md`](STATE.md): current runs, measured results, blockers, and next
  triggers.
- [`EXPLORATION.md`](EXPLORATION.md): what has been inspected and what the
  evidence currently says.
- [`HYPOTHESES.md`](HYPOTHESES.md): candidate product improvements, expected
  effects, disconfirmers, and ablations.
- [`DECISIONS.md`](DECISIONS.md): methodological decisions and why they were
  made.

Update these files whenever a result changes the frontier. Do not record API
keys, credentials, or frozen-final labels here.
